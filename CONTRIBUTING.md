# Contributing

Contributions should begin with a public source, not a conclusion about Jamie.

1. Identify the public source and its stable locator.
2. State what it establishes and what it does not establish.
3. Choose one canonical home under `library/`.
4. Link to an existing canonical transcript rather than copying it.
5. Preserve collective credit and distinguish presence, participation,
   collaboration, supervision, relationship, and endorsement.
6. Run `npm run check`.

Private correspondence, raw transcript exports, recommendation letters,
unapproved photographs, local archive paths, credentials, contact details, and
unrelated third-party information do not belong here.
