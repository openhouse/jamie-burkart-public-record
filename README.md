# Jamie Burkart Public Record

This repository is a Jamie-centered public-source edition: a navigable record
of public words, public work, public encounters, institutional descriptions,
and published reception connected to Jamie Burkart's practice.

The current repository is a **private, public-safe implementation candidate**.
It contains no private correspondence, private transcript bodies, photo pixels,
or unpublished recommendation research. Public release remains a separate
human decision.

## Canonical-home rule

Each record has one canonical Markdown home. When a complete public statement
is already maintained in a subject-specific source edition, this repository
links to the pinned canonical record rather than duplicating its body. Browse
pages are generated relative-link indexes, not second copies.

## Trust boundary

Access is not consent, evidence is not publication permission, and repository
presence is not portfolio placement. Rights, attribution, collective credit,
represented-person review, editorial selection, and publication authority are
separate gates. See [Governance](GOVERNANCE.md).
