# Research access note

The initial implementation used two distinct browser surfaces without changing
the authenticated UCSC session already open in Chrome.

- The in-app browser ran bounded public searches for Jamie Burkart with Studio
  3 in Innsbruck, the Weibel Institute in Vienna, and the MIT Media Lab.
- Those searches did not return a reliable public event record establishing
  Jamie's participation, date, role, or words.
- Chrome was used to verify the existing `jamieburk.art` RFC pull request and
  its base and head branches.

Search failure is not proof that no public source exists. The three encounter
records remain public-coverage gaps, and protected research remains a lead for
future narrow retrieval rather than a substitute for public evidence.
